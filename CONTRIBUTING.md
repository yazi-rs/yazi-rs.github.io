# Contributing

Thank you for helping improve the documentation!

## Documentation versions

The documentation has two versions:

- The newest release in `/versioned_docs/version-*/`.
- The nightly documentation in `/docs/`.

## Pull requests

Choose the change type that matches both the documentation and the Yazi version it describes:

- **New**: the change only applies to the nightly documentation and the nightly version of Yazi.
- **Amend**: the change targets the newest released documentation and the newest stable version of Yazi; the same documentation change has also been synced to the nightly documentation.

Please follow the [pull request template](https://github.com/yazi-rs/yazi-rs.github.io/blob/main/.github/pull_request_template.md) before submitting.
